# 存到旅記：iOS 分享 → Notion

在 IG、Threads、Safari、相簿等 App 按「分享」並選「存到旅記」後，會在 Notion「收藏卡片」新增一張卡片，並依你在「分類樹」設定的關鍵字自動掛上分類。不需要伺服器，也不用 AI。

運作方式：

1. **捷徑**：接收分享內容，若是截圖，就在手機上用內建 OCR 讀出文字。
2. **Scriptable 腳本**（[save-to-travel-notes.js](save-to-travel-notes.js)）：抓網頁標題，讀取 Notion 分類樹並比對關鍵字，再建立卡片。
3. 找不到分類，或有好幾個分類同分時，會跳出清單讓你選。

---

## 一、事前準備（只做一次）

1. Notion「旅記收藏」頁面右上角點「⋯ → 連接」，加入你的整合「旅遊收藏」。
2. 準備好這個整合的金鑰（Notion「設定 → 連接 → 開發或管理整合」，開頭是 `ntn_` 或 `secret_`）。**不要貼給任何人**，第一次執行時直接貼進手機即可。
3. 在 App Store 安裝免費的 **Scriptable**。

## 二、安裝腳本

1. 在 iPhone 上打開 [腳本原始碼（raw）](https://raw.githubusercontent.com/chiubi-hub/travel-notes/main/shortcuts/save-to-travel-notes.js)，全選後拷貝。
2. 打開 Scriptable，按右上「＋」，貼上程式碼。
3. 點上方的標題，把名稱改成 **存到旅記**，然後按「Done」。

## 三、建立捷徑

打開「捷徑」App，按「＋」新增捷徑，名稱設為 **存到旅記**，然後依序加入以下動作：

| # | 動作（搜尋這個名稱） | 設定 |
|---|---|---|
| 1 | 取得輸入中的 URL（Get URLs from Input） | 輸入：捷徑輸入 |
| 2 | 從輸入取得文字（Get Text from Input） | 輸入：捷徑輸入 |
| 3 | 如果（If） | 條件：「URL」**沒有任何值** |
| 4 | 　從輸入取得影像（Get Images from Input） | 放在「如果」裡面，輸入：捷徑輸入 |
| 5 | 　從影像擷取文字（Extract Text from Image） | 放在「如果」裡面，影像：上一步的影像 |
| 6 | 　設定變數（Set Variable） | 放在「如果」裡面，變數名稱：`OCR`，值：擷取的文字 |
| 7 | 結束如果 | 「如果」動作會自動附上，「否則」區塊留空即可 |
| 8 | 字典（Dictionary） | 加三個文字欄位：`url` → URL、`text` → 文字、`ocr` → 變數 OCR |
| 9 | Run Script（Scriptable） | Script：存到旅記；Parameter：字典；開啟 **Show When Run** |
| 10 | 顯示通知（Show Notification） | 內容：Run Script 的結果 |

最後點下方的「ⓘ」：

- 開啟「**在共享表單中顯示**」。
- 接收類型只留：**影像、URL、文字、Safari 網頁**。

## 四、測試

1. 在 Safari 打開任一篇旅遊文章，按「分享」→「存到旅記」。
2. 第一次會要求貼上 Notion 金鑰，貼上後按「儲存」。
3. 看到「已存到旅記」通知後，到 Notion「收藏卡片」確認是否多了一張。

截圖的測試方式：從相簿分享一張有店名的截圖，卡片內文會出現「截圖文字」。

## 設定分類

分類都在 Notion「分類樹」裡設定：

- **新增節點**：新增一列，填寫「名稱」，然後在「上層分類」選它的父節點（最上層就留空）。
- **關鍵字**：以逗號分隔，例如 `咖啡,cafe,coffee,カフェ`。節點名稱本身也會被當成關鍵字。
- **計分方式**：從根節點到某個節點的路徑上，關鍵字有出現的節點越多，分數越高。
  - 例如文字裡有「京都」和「咖啡」，就會選到「美食地點 › 日本 › 京都 › 咖啡」。
  - 若有好幾個分類同分，會跳出清單讓你選。

## 常見問題

| 訊息 | 原因與處理 |
|---|---|
| 找不到 Notion 資料庫 | 「旅記收藏」頁面還沒連接「旅遊收藏」整合（見準備第 1 步） |
| Notion 金鑰無效，已清除 | 金鑰貼錯了，下次執行時重新貼上即可 |
| IG 卡片標題只有網址 | IG 會擋住外部讀取。建議先截圖，再把截圖一起分享進來 |
| 沒有跳出選單 | 確認第 9 步的 Show When Run 已開啟 |
