# 旅記「收藏」分頁的中繼服務（Google Apps Script）

旅記網頁不能直接讀取 Notion，因為瀏覽器會擋下這種請求。所以我們用你自己的 Google 帳號，在 Google Apps Script 上放一支小程式 [Code.gs](Code.gs)，由它代為轉送。

- 免費，不用綁信用卡。
- Notion 金鑰只存在你的 Apps Script 專案裡，不會出現在網頁或 GitHub。
- 旅記連線時要輸入你自己訂的密碼（APP_KEY）。

建議用 Mac 的瀏覽器操作，大約 10 分鐘。

## 1. 建立專案、貼上程式

1. 打開 <https://script.google.com/>，用你的 Google 帳號登入，按左上「**新專案**」。
2. 點左上角的「未命名的專案」，改名為 `旅記收藏`。
3. 編輯器裡已經有一段 `function myFunction() {…}`，把它**全部刪掉**。
4. 打開 [Code.gs 原始碼（raw）](https://raw.githubusercontent.com/chiubi-hub/travel-notes/main/gas/Code.gs)，全選、拷貝，貼進編輯器。
5. 按上方的磁碟圖示（儲存）。

## 2. 設定金鑰和密碼

1. 點左側齒輪圖示「**專案設定**」。
2. 捲到最下面的「**指令碼屬性**」，按「**新增指令碼屬性**」，加入下面兩筆：

| 屬性 | 值 |
|---|---|
| `NOTION_TOKEN` | Notion 整合「旅遊收藏」的金鑰（就是捷徑用的那一把，`ntn_` 或 `secret_` 開頭） |
| `APP_KEY` | 自己訂一組密碼，例如一串英文加數字 |

3. 按「**儲存指令碼屬性**」。

## 3. 部署成網頁應用程式

1. 按右上藍色「**部署**」→「**新增部署作業**」。
2. 點「選取類型」旁的齒輪，選「**網頁應用程式**」。
3. 填寫設定：
   - 說明：隨意，例如 `v1`
   - 執行身分：**我**
   - 誰可以存取：**所有人**（不用擔心，沒有密碼的人拿不到資料）
4. 按「**部署**」→「**授權存取**」→ 選你的 Google 帳號。
5. 會看到「Google 尚未驗證這個應用程式」，這是因為程式是你自己寫的，屬於正常狀況。按左下「**進階**」→「**前往「旅記收藏」（不安全）**」→「**允許**」。
6. 拷貝畫面上的「**網頁應用程式網址**」，格式是 `https://script.google.com/macros/s/…/exec`。

想確認是否成功：把網址貼到瀏覽器打開，看到「旅記收藏中繼服務運作中」就代表 OK。

## 4. 在旅記連線

1. 打開旅記，切到最左邊的「**收藏**」分頁。
2. 貼上網址、輸入 APP_KEY 密碼，按「連接」。

## 之後程式更新時

1. 把新版 Code.gs 貼上並儲存。
2. 按「部署 → 管理部署作業」→ 鉛筆圖示 → 版本選「**新版本**」→「部署」。

網址不會改變，旅記不用重新設定。

## 常見問題

| 畫面上的訊息 | 原因 |
|---|---|
| 密碼不正確 | 旅記填的密碼和 APP_KEY 不一樣 |
| 尚未設定指令碼屬性 | 第 2 步沒有儲存，或屬性名稱拼錯（要全大寫） |
| 連線失敗 | 網址要是 `/exec` 結尾，且「誰可以存取」要選「所有人」 |
| Notion：Could not find database… | 「旅記收藏」頁面沒有連接「旅遊收藏」整合 |
